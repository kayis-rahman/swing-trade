# strategy

Go module `github.com/kayis-rahman/swing-trade/go/strategy`, corresponding to Gradle module `backend/strategy`. Owns indicators, signals, strategies, gates and backtest engines. May import `github.com/kayis-rahman/swing-trade/go/core`, `github.com/kayis-rahman/swing-trade/go/data` and `github.com/kayis-rahman/swing-trade/go/llm` only.

Package layout mirrors `backend/strategy/src/main/java/com/swingtrade/strategy/`.
