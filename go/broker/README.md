# broker

Go module `github.com/kayis-rahman/swing-trade/go/broker`, corresponding to Gradle module `backend/broker`. Owns paper trading, risk controls and broker-facing services. May import `github.com/kayis-rahman/swing-trade/go/core`, `github.com/kayis-rahman/swing-trade/go/data` and `github.com/kayis-rahman/swing-trade/go/strategy` only. Live order placement remains out of scope.
